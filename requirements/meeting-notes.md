## 📌 Повестка
*   Анализ причин систематического нарушения сроков выдачи результатов (TAT) по ПЦР-исследованиям.
*   Поиск узких мест на преаналитическом этапе (маршрутизация биоматериала) и аналитическом этапе (учет расхода реагентов).
*   Обсуждение требований к интеграции роботизированных станций дозирования с новой ЛИС.

## 🎯 Принятые решения
1.  **Отказ от ручной сортировки:** Подтверждено, что визуальная сортировка пробирок по цвету крышки приводит к ошибкам маршрутизации и задержкам, так как цвет (например, желтый) дублируется для разных отделов.
2.  **Новый алгоритм штрихкодирования:** Утвержден переход от старого формата (только ИНЗ) к 12-значной структуре: **ИНЗ / Корень заказа (9 цифр) + Код контейнера (3 цифры)**.
3.  **Автоматизированная маршрутизация:** Трехзначный Код контейнера станет главным ключом в БД для однозначной идентификации типа биоматериала и целевого отдела (ПЦР, ИФА). Маршрутизация будет строго контролироваться системой через сканирование штрихкода, исключая визуальный фактор.
4.  **Внедрение автоматического Lot Tracking:** Ручной подсчет лунок и списание реагентов лаборантом упраздняются. Утверждено решение списывать тесты из партий автоматически в момент генерации виртуального штатива.
5. **Жесткая блокировка (Hard Stop) при неверной маршрутизации:** При сканировании пробирки с кодом контейнера другого отдела система блокирует добавление в виртуальный штатив, не списывает реагенты и выводит предупреждение с указанием целевого отдела.
6. **Расчет на утренний пик:** Система должна выдерживать пиковую нагрузку утреннего приема (с 08:00 до 11:00) без задержек сканирования и потери событий интеграции.
7. **Аварийный офлайн-регламент (для экстренных проб):** При временной недоступности ЛИС работа с пробирками опирается на 12-значный штрихкод (`ИНЗ + Код контейнера`) и журнал смены для экстренных проб с последующей синхронизацией после восстановления связи.
